# go-exercises

Go 学习练习合集，按阶段项目分目录，每个项目独立 `go.mod`，进对应目录 `go run .` 即可。

| 项目 | 阶段 | 状态 | 覆盖 |
|------|------|------|------|
| [todo-cli](./todo-cli/) | 阶段一：基础语法 | ✅ 2026-08-22 完成 | struct / slice / 指针 / 方法 / 包 / 错误处理 / JSON / 文件 IO |
| url-checker | 阶段二：Go 精髓 | 未开始 | interface / goroutine / channel / select / context |
| comment-api | 阶段三：后端工程（capstone） | 未开始 | Gin / GORM / SQL 事务 / Redis / 测试 |

零散小练习（divmod 之类）放 `exercises/`，做到再建。
